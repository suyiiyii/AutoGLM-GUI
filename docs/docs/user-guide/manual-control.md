## 🎮 手动控制模式

除了 AI 自动化，你也可以直接在实时画面上操控手机，并通过实时视频流观察设备状态：

<img width="1384" height="835" alt="d50683ce7777fe0ca6342f1269052448" src="https://github.com/user-attachments/assets/613f8d09-1a6a-4d75-ac4a-a3736b9a878d" />

1. **实时画面** - 设备面板右侧显示手机屏幕的实时视频流（基于 scrcpy）
2. **点击操作** - 直接点击画面中的任意位置，操作会立即发送到手机
3. **滑动手势** - 按住鼠标拖动实现滑动操作（支持滚轮滚动）
4. **视觉反馈** - 每次操作都会显示涟漪动画和成功/失败提示
5. **精准转换** - 自动处理屏幕缩放和坐标转换，确保操作位置准确
6. **显示模式** - 支持自动、视频流、截图三种显示模式切换

## 实时画面与预览

在任务执行时，右侧会显示设备实时画面，便于你观察 AI 当前的操作。

- 看到设备屏幕的实时变化
- 对执行中的任务进行观察与判断
- 在手动控制模式下直接点按操作

## 直接操控与截图

- 点击屏幕任意位置进行点按
- 鼠标拖动进行滑动
- 系统会自动处理坐标缩放，确保点击准确
- 任务执行中或空闲时均可进行截图，用于确认当前屏幕状态
