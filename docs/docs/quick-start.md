## 🚀 快速开始

本页作为“开始使用”章节的索引，提供最短路径的四个步骤。点击每一项即可查看维护中最准确的版本：

1. **安装与运行**：请参见 [安装与启动](/docs/getting-started/install) 了解桌面版、Python 包和 `uvx` 的区别，以及推荐的命令组合。
2. **首次启动**：归纳在 [首次流程指南](/docs/getting-started/first-run)，告诉你应该先做哪些界面配置、如何初始化模型和设备。
3. **模型配置**：使用 [模型配置](/docs/getting-started/model-config) 页面完成 Base URL、模型名称和 API Key 的填写，同时了解参数含义。
4. **设备连接**：在 [设备连接](/docs/getting-started/device-connection) 页面查看 USB/WiFi/二维码配对的完整步骤，包含关键按钮名和状态反馈。

使用过程中如果需要“快速回顾”，欢迎直接返回本页，在“开始使用”目录继续跳转。
